# python-lessons
## Ввод и вывод данных
```python
print('привет')
```
функция **print** выводит сообщения и данные сохраненные в переменной на экран
```python
input('введите целое число')
```
функция **input** позволяет получать данные с клавиатуры получаемые данные не сохраняются автоматически
> [!WARNING]
> функция **input** воспринимает любые данные как текст
